# SmartComanda ULTIMATE 6.0 - Sistema de Chat Integrado

Este pacote contém os arquivos atualizados para corrigir e habilitar o chat em tempo real entre o **Dashboard do Estabelecimento** e o **Celular do Cliente**.

## Arquivos Incluídos:
1. `dashboard_chat.html` - Interface administrativa para o atendente/gerente visualizar as mesas e responder os clientes.
2. `cliente_chat.html` - Interface otimizada para o smartphone do cliente na mesa.

## Como testar:
1. Abra `dashboard_chat.html` e `cliente_chat.html` em abas separadas do seu navegador.
2. Envie mensagens de qualquer um dos lados; elas serão sincronizadas instantaneamente via armazenamento local em tempo real.
